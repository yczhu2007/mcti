# 五维道具匹配：IPIP筛题改编版

在原生HTML/CSS/JS架构中保留16件道具、原版物品栏图标、图鉴、进度恢复、五维雷达图、TOP3、结果图预览下载和重测。当前仅本地修改，没有提交、推送或部署。

## 题库来源与适配

检查了bigfive-web、IPIP-NEO-PI两个开源项目，并直接对照IPIP官方题目与计分键筛选。30题中29条来自IPIP-NEO-120，1条反思题来自Big-Five Factor Markers。检索地址、授权和筛选理由见 [question-sources.md](question-sources.md)，逐题原文、出处、方向和中文改编见 [selected-question-sources.json](selected-question-sources.json)。

每维6题，采用2道四项情境单选、1道二选一、3道五档选择，交错呈现。N按神经质方向计分，页面称为“情绪敏感度”。选择不同日常侧面，避开直接同义反复、政治候选人偏好和物质滥用题。开放性不以词汇量或学业能力为主要依据。

英文原条目为公有领域。中文、选项、题数缩减和题型变化均为本站改编，未继承完整原量表的信效度，也不宣称正式中文版效度。来源侧面仅供追溯，不作为验证过的分量表输出。

五档记1/2/3/4/5，四项记1/（7/3）/（11/3）/5，二选一记1/5；按原条目方向将反向题用6减原分。每维等权平均，`x=(均值−3)/2`转换到[-1,1]；图表用`(x+1)×50`转成0～100。不同题型最大贡献相同，但回答方差未校准。用户分数不二值化、不排序拉伸、不为雷达图制造差异。

新存储键mcti-ipip-selected-30-v4，不混用、不删除旧题库的回答。

## 轮廓匹配与绝对契合

本次区分两个指标，页面、TOP3及PNG统一使用它们：

```
x_j = (维度均值−3)/2            // 五维以量表中点为零
cos = dot(X,P) / (norm(X)×norm(P))
轮廓匹配度 = (1+cos)×50          // 方向比较
绝对契合度 = mean(100−|u_j−a_j|) // 保留实际刻度强弱
u_j = (x_j+1)×50, a_j = (p_j+1)×50
倾向幅度 = norm(X)/sqrt(5)       // 0～1，实际偏离中点的程度
```

余弦方向一致为100%，垂直为50%，相反为0%。数值归一化后会改变百分比的含义：轮廓指标衡量五维偏向的形状；绝对指标衡量原刻度上的距离。两者一同展示，原五维分数保持原样。

方法参考 [YSocialTwin/YSimulator人格轮廓推荐](https://github.com/YSocialTwin/YSimulator/blob/main/docs/features/RECOMMENDATION_SYSTEMS.md) 的余弦相似度，以及 [scikit-learn的余弦定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.pairwise.cosine_similarity.html)。该推荐项目文档组合了兴趣和人格；本站采用人格向量比较的思路，并将五维以量表中点为零。JS实现由本站独立编写。

核对过的 [bigfive-web评分源码](https://github.com/rubynor/bigfive-web/blob/master/packages/score/src/index.ts)按维度累加、计数并依据均值解释。本站保留等权均值计分。IPIP的[常模建议](https://ipip.ori.org/newNorms.htm)强调同一工具与参照人群的对应关系；本站改编题库的验证和常模属于后续工作。

当前16个道具原型长度相等，因此对于同一份回答，余弦与原始点积具有相同排序。原始分差、温度0.10和五维得分保留。百分比差距扩大体现了方向归一化；候选的原始接近程度继续如实显示。两项指标均用于本站创作性道具比较，心理测量可靠性和真实推荐效果需要另外收集数据评估。

### 接近中点与并列

完全中点或数值近零的向量按中性相似度0处理，16件道具均显示50%并列。较弱且非零的向量仍能具有明确方向，因此可能出现较高轮廓匹配度。主卡保留其绝对契合度，并提示方向指标较敏感。`lowSignalThreshold=0.15`是可配置的界面提示边界，尚待真实数据校准。

`discrimination`继续使用原始分差0.06阈值；倾向幅度较小时同样给出low标记。扩大后的轮廓百分比配合接近提示一同阅读。余弦归一化本身保留方向、舍去长度；本项目通过额外显示绝对契合度、保存倾向幅度和原始五维来完整保留长度信息。

采用1e-12浮点容差标记和排序并列；同组按图鉴顺序稳定展示。首两名原始分差下限取0，避免浮点误差形成负零分差。TOP3保留竞赛排名，tiedFirst保留所有并列第一。

### 测试覆盖

检查方向一致、相反、垂直、五维参与、零向量、近零、弱向量、强向量、并列与接近结果。特别比较同方向不同长度的两份合成向量：轮廓指标相同，绝对指标和倾向幅度不同，较弱结果附有接近提示。这是本次保留事实信息的主要检查。

## 以性格为主的解读

`dist/interpretation.js`按真实五维刻度选取行为描述：低于35、35～65、高于65各有一组行为描述。这些分段用于本站日常解读。整体解读选较明显的两个侧面，并在特定组合中补充日常表现；每个维度另有标题、描述和提醒。完全居中时承认两端之间的倾向，不编造鲜明性格。

分析区域直接描述做事、交流、相处和压力反应，计算定义放在独立说明中。物品联想独立放在“为什么是这件道具”区域。候选卡展示各道具的五维设定画像；数学计算放入可展开的说明。

## 局限与验证

偶校验不能保证唯一最近点：全零向量16项相同；全正等强向量有5个最近原型。16件物品是均匀数学原型加创作性关联，不是16种科学人格类别。完整五维保留，但不能涵盖人的全部个性。图表可均衡，结果可能并列；即使匹配度很高，也不是心理诊断。
