# MCTI · 你的本命道具

用户于 2026-10-18 确认开始制作。主题：如果只能给你一件 MC 里的游戏道具，哪件最适合你？

## 内容与流程
首页 → 32 道日常选择 → 结果。八项独立连续特质：前瞻筹划、机制钻研、创意联想、行动决断、细节觉察、群体照应、自主边界、临场应变。不使用人格类型组合。
二选一、四项情境单选、五项选二、五档倾向量表各 8 题。每个维度 4 题，每种题型各一题。混合穿插；无文字输入。答题后手动下一题，允许返回修改；浏览器本地恢复进度。
结果包含 16 件预定道具之一、图片、匹配度、命中特质及解释、评语、八维雷达图和数值、TOP3、预览并下载 PNG 结果图、重新测试。

## 评分
每个选项有固定的 0–100 强度。二选一为 0/100；单选四档为 0、100/3、200/3、100；量表为 0/25/50/75/100，反向题反转。多选题五项为 0/25/50/75/100，选两项均值按可达区间 12.5–87.5 归一化到 0–100。各维度四题等权平均。
每件道具有一组八维目标向量；匹配度为 100 减去八维均方根距离，四舍五入显示。相近或并列匹配明确提示，排序稳定。匹配度不是概率或经过验证的心理测量指标。道具解释采用用户实际较接近该道具的特质；不把低分写成缺陷。

## 视觉与交付
原生 HTML/CSS/JS，无框架依赖。深矿绿、草绿、暖白和少量经验金；中文像素字体；切角、方块材质、物品栏与浮空小岛为主要视觉。支持手机、键盘操作和减少动画设置。
字体与道具图片本地托管，结果图使用 Canvas 绘制，不依赖截图服务。PNG 包含道具、匹配度、评语、八维评分、TOP3。网站通过公开 GitHub 仓库与 GitHub Pages 发布，交付源码和访问地址。

## 验收
检查题型/选项/题量；八维各四题；16 件道具的差异与自身向量可达性；评分边界和稳定并列；完整答题、返回、多选校验、刷新恢复、重测、导出 PNG；桌面与手机布局；生产资源可用。
